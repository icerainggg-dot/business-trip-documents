출장비 증빙서류 취합

영수증·확인서·지도 캡처·공문을 한꺼번에 올리면 자동으로 분류하고, 빠진 서류와 불일치 항목을 알려줍니다. 파일은 이 PC의 브라우저 안에서만 처리되며 서버로 전송되지 않습니다.

1특이사항 선택 입력 · 적은 내용이 증빙서류의 출발/도착 칸에 그대로 들어갑니다

AI로컬 LLM 연결 사용 안 함

연결하면 서류마다 AI가 이미지와 글자를 직접 읽어 종류·실제 출발일·구간·편명·금액을 판독하고, 출발/경유/도착 구분과 점검 결과를 AI가 먼저 정리합니다. 빈 곳은 기존 규칙으로 채웁니다. 서류는 이 PC(또는 지정한 사내 서버)의 LLM으로만 보내집니다.

브라우저에서 바로 호출합니다. 이 페이지를 localhost가 아닌 주소(사내 서버 등)로 열면 LLM 서버에서 그 주소를 허용해야 합니다 — Ollama: 환경변수 OLLAMA_ORIGINS, vLLM: --allowed-origins.
